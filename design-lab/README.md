# ParkFair Phase 3 design laboratory

Run from PowerShell:

```powershell
Start-Process 'E:\ParkFair\design-lab\index.html'
```

Use the top navigation to view the resident home/garage comparisons, the 15-screen library, the guided administrator stages, and the asset studies. Each image opens at full resolution. Play the motion study, toggle reduced motion, use arrow keys on the garage image or zoom with the labeled controls, and select bays using the keyboard or pointer. The chart filter accepts synthetic flat or bay values.

For static review:

```powershell
Start-Process 'E:\ParkFair\docs\design\phase-3\previews\resident-homes.png'
Start-Process 'E:\ParkFair\docs\design\phase-3\previews\resident-garages.png'
Start-Process 'E:\ParkFair\docs\design\phase-3\previews\admin-publication.png'
```

The gallery needs no account, development server or device. Existing applications never load it. See the [owner review package](../docs/design/phase-3/REVIEW_PACKAGE.md) and [approval register](../docs/design/phase-3/APPROVAL_REGISTER.md).
